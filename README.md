# 🎮 Tic-Tac-Toe Game (C# WinForms)

A classic Tic Tac Toe game built using **C# Windows Forms**, featuring a clean graphical interface where two players can play against each other on the same machine.

## 📌 Features
- 2-player mode
- Modern Windows Forms interface
- Real-time turn indicator
- Game result detection (Win / Draw)
- Reset game button
